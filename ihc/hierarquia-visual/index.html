Minicurso para front-enders

HTML5

O HTML é o Alicerce da Web! Aprenda a base fundamental de todos os sites. HTML é o esqueleto que sustenta o conteúdo.

Crie o alicerce sólido do seu projeto web! Conteúdo do curso:

  • Tags Fundamentais e Estrutura Básica
  • HTML Semântico
  • Formulários e Entradas de Dados
  • Mídia e Links.

CSS3

O CSS cria páginas com estilo e um design impressionante! Transforme estruturas simples em layouts incríveis. CSS é a arte que embeleza a web.

Cor, layout, responsividade e animações! Conteúdo do curso:

  • Sintaxe, Seletores e Especificidade
  • Modelo de Caixa (Box Model)
  • Layout Moderno (Flexbox e Grid)
  • Design Responsivo.

JavaScript

A Mágica da Interatividade! Crie experiências dinâmicas e interativas. O JavaScript dá vida e lógica às páginas web.

Eventos, animações complexas, etc. Conteúdo do curso:

  • Fundamentos e Sintaxe
  • Funções e Escopo
  • Manipulação da DOM
  • Eventos e Interatividade.
